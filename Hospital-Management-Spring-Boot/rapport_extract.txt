Sujet

L’objectif principal consiste à concevoir et réaliser une application web dynamique avec
le Framework Spring qui permet la gestion d’un hôpital. Les données sont stockées
dans une base de données MySQL
L’application se compose de trois couches :
La couche DAO qui est basée sur Spring Data, JPA, Hibernate et JDBC.
La couche Métier
La couche Web basée sur MVC coté Serveur en utilisant Thymeleaf.
La sécurité est basée sur Spring Security
